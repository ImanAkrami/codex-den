# Code of conduct

Be respectful, constructive, and patient. Welcome questions and differing experience. Focus feedback on behavior and evidence, and correct mistakes without personal attacks.

Harassment, threats, discrimination, sexualized conduct, doxxing, and sustained personal attacks are unacceptable in project discussions, issues, reviews, and events. Do not share another person's private information.

Maintainers may edit or remove inappropriate content, restrict participation, or exclude repeat or serious offenders. Apply decisions proportionately, respect privacy, and explain moderation decisions where appropriate.

## Report a concern

Use GitHub's **Report content** action on the relevant issue, comment, or profile, or [submit a private abuse report to GitHub Support](https://support.github.com/contact/report-abuse). Reports submitted through that route go to GitHub's moderation team; do not assume project maintainers can view them. Maintainers can also moderate public project content directly.

Do not disclose sensitive personal details in public issues. Software vulnerabilities use the separate [private security-reporting route](SECURITY.md).
